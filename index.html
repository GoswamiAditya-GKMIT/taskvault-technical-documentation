    TaskVault - Technical Documentation

    Problem Statement

    Traditional task management systems often struggle with scalability and data isolation when serving multiple client organizations. Single-tenant deployments are costly to maintain, while poorly designed multi-tenant architectures risk data leakage. Furthermore, basic task trackers lack the auditability and role-based governance required by enterprise teams, leading to unmanaged access and untrackable changes.

    Proposed Solution

    TaskVault addresses these challenges with a multi-tenant, API-first backend.

    • It enforces strict data isolation using Organization IDs across all entities.
    • It implements a 3-tier role system (Super Admin, Tenant Admin, User) to ensure granular access control.
    • It provides immutable audit logs for task history and soft-deletion mechanisms to guarantee data integrity and recovery.
    • It integrates Razorpay for seamless subscription billing and Celery/Redis for high-performance background processing.

    Project Overview

    TaskVault is a multi-tenant application where data is strictly isolated by Organization.

    Core Tenets

    • A User belongs to exactly one Organization.
    • A Task belongs to exactly one Organization.
    • Cross-tenant access is strictly blocked. Users cannot view or modify data from other organizations.

    User Roles

    1. SUPER_ADMIN: Platform owner. Manages Organizations and Tenant Admins. Cannot participate in daily task management.
    2. TENANT_ADMIN: Organization manager. Manages Users and Tasks within their Organization.
    3. USER: Standard employee. Manages their own tasks and assignments.

    Key capabilities include

    • Multi-Tenancy: Complete data isolation per organization.
    • Role-Based Access Control (RBAC): Granular permissions for Super Admins, Tenant Admins, and standard Users.
    • Subscription Management: Integration with Razorpay for handling premium organization subscriptions.
    • Audit Trails: Immutable history logging for critical task changes.
    • Scalable Architecture: Optimized for performance with database indexing and efficient query structures.

    Key Features & Enhancements

    1. Multi-Tenancy Architecture

    • Organization-First Approach: Every user and task is scoped to a specific organization.
    • Data Isolation: Strict permission checks ensure users can never access data outside their organization.
    • Tenant Management: Super Admins can oversee all organizations, while Tenant Admins manage their specific instance.

    2. Advanced Permission System

    • Super Admin: System-wide access, mostly for maintenance and oversight.
    • Tenant Admin: Complete control over their organization's users, tasks, and billing.
    • User: varying levels of access to tasks (create, view, edit) based on ownership and assignment.

    3. Subscription & Billing

    • Lifetime Premium Plans: Organizations can upgrade to premium status.
    • Payment Processing: Secure integration with Razorpay for payment capture and verification.
    • Webhook Handling: Robust processing of payment events (success/failure) to maintain state consistency.

    4. Task Management

    • Subtasks: Support for breaking down tasks into smaller subtasks (1-level nesting).
    • History Tracking: every status or priority change is recorded in TasksHistory for accountability.
    • Soft Deletion: All major entities (Users, Tasks, Comments) support soft deletion to prevent accidental data loss.

    Objectives

    Goal Description
    Multi-Tenancy Secure isolation of data across different organizations.
    RBAC distinct roles (Super Admin, Tenant Admin, User) with specific privilege sets.
    Auditability Full tracking of task mutations and payment events.
    Monetization Built-in subscription flows for premium organization features.
    Security JWT authentication, email verification, and secure password handling.
    Performance Optimized database schema with appropriate indexing for common queries.
